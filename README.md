# Django Local Library

첫 회사인 **(주)가이온**에서 솔루션개발팀으로 부서 이동을 준비하며 Django를 학습하기 위해 만든 프로젝트입니다.

Django 공식 문서를 참고하여 도서관의 도서와 대출 정보를 관리하는 웹 애플리케이션을 구현했습니다.

## 주요 기능

- 도서, 저자, 장르 및 언어 정보 관리
- 도서 사본과 대출 상태 관리
- 도서 및 저자 목록·상세 조회
- 로그인한 사용자의 대출 도서 조회
- 사서 권한에 따른 대출 도서 관리 및 반납일 연장
- 도서관 데이터 생성, 수정 및 삭제
- Django 관리자 페이지 활용
- 페이지네이션과 사용자 권한 처리

## 사용 기술

- Python
- Django 5.1
- SQLite
- Django Template
- HTML / CSS

## 학습 내용

- Django 프로젝트와 앱 구조
- URL 라우팅과 View
- Django ORM을 이용한 모델 설계
- 함수형 및 클래스형 View
- Template과 Form 처리
- 사용자 인증과 권한 관리
- 관리자 페이지와 테스트 코드 작성

## 프로젝트 목적

솔루션개발팀 업무에 필요한 Django의 기본 구조와 웹 애플리케이션 개발 흐름을 익히고, 모델부터 화면까지 직접 구현해 보기 위해 진행한 학습 프로젝트입니다.
